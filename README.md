# Latent Archive

Independent React/Vite frontend for an authorized episode archive.

Stack: React + Vite + Supabase + GitHub Pages.

The frontend uses only the Supabase publishable key. Never add a Supabase secret/service-role key.

The existing Supabase project already has the episode/contact tables and RLS policies.

Run locally with:
npm install
npm run dev

GitHub Pages:
Settings -> Pages -> Source -> GitHub Actions.
